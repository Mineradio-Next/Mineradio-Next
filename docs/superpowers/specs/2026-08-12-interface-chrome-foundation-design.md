# 搜索与播放器界面底座设计

## 目标

为搜索区和底部播放器建立稳定的结构、视觉层级与扩展规则。后续增加来源、筛选、播放工具或扩展能力时，只能进入预先定义的槽位，不再通过临时加宽、缩小按钮或向现有空隙追加控件改变整体布局。

本设计取代 `2026-08-12-search-glass-clarity-design.md` 中“搜索历史沿用独立表面”的决定。搜索历史和搜索结果必须共享同一工作区外壳。

## 共同设计原则

- 延续 Mineradio 原版的轻玻璃、悬浮感和克制动效。
- 外壳负责背景、边界和模糊，内部内容不重复叠加面板。
- 每类内容使用固定槽位、固定基准线和明确的主次关系。
- 图标按钮只在悬停、聚焦或激活时显示明显表面反馈。
- 动效只使用 `opacity` 和 `transform`，时长控制在 180 至 240 毫秒。
- 复杂功能可以打开独立面板，不能被强行压进视觉工作台或小型弹层。

## 搜索工作区

### 结构

搜索区分为两个同轴区域：

1. 独立搜索框。
2. 统一搜索工作区，包含来源、当前检索信息、内容筛选以及内容视口。

内容视口在搜索历史、加载状态、空状态和搜索结果之间切换。所有状态必须使用相同宽度、相同中心线、相同左右内边距，不允许负边距或状态切换时横向跳动。

### 扩展规则

- 新来源进入来源槽位；空间不足时横向滚动，不扩大外壳。
- 新筛选进入筛选槽位；筛选项过多时使用受控折叠，不换行挤压结果。
- 专辑、歌手、播客等新搜索类型替换内容视口，不创建新的外层搜索面板。
- 外壳仅在存在历史、加载或结果内容时显示。

### 玻璃和背景

- 搜索框保留独立轻玻璃表面。
- 搜索工作区使用一层低对比玻璃边界，不使用黑色厚重底板。
- 首页或歌词存在文字时，由工作区外壳局部模糊并降低其背后内容的亮度，背景颜色和轮廓继续可见，文字不得可读。
- 纯动画背景保持更通透的第一版效果。

## 播放器底座

### 结构

播放器包含一条进度轴和一个三段控制区：

- 左侧歌曲区：封面、歌名、歌手、来源/会员/音质状态、喜欢、收藏到歌单。
- 中间核心区：上一首、播放/暂停、下一首。该区域始终锁定在播放器视觉中心。
- 右侧工具区分为三组：标准播放工具、原版界面功能、扩展入口。

进度轴左端显示当前时间，右端显示总时长。时间不再占用右侧工具区。

### 常驻控件

- 标准播放工具：播放模式、歌词、当前队列、音量。
- 原版界面功能：控制条自动隐藏、沉浸模式、全屏。
- 扩展入口：位于播放器最右侧，打开独立的播放器工具面板。

喜欢与收藏到歌单始终常驻歌曲区。原版界面功能始终常驻，不进入扩展面板。

### 扩展面板

- 播放工具组初始包含 AutoMix、听感调节和定时停播。
- 新的普通播放能力默认注册到扩展面板，不能直接追加到播放器主行。
- 扩展面板使用分组列表，不使用卡片套卡片。
- 复杂工具从扩展面板进入自己的独立面板，扩展面板只承担入口和状态反馈。

### 响应式规则

- 宽窗口使用单行三段控制区。
- 中等窗口缩短歌曲文字并收紧组内间距，但不缩小核心播放按钮。
- 空间不足时使用有秩序的双层排布，保留全部核心和原版界面功能。
- 不通过连续缩小所有按钮、隐藏核心控件或允许区域互相覆盖解决空间不足。

## 扩展注册规则

每个新增播放器能力必须声明一种位置：

- `core`：上一首、播放/暂停、下一首，不接受新增项。
- `standard`：所有播放器普遍需要的常驻操作，需要明确设计评审。
- `original`：Mineradio 原版核心界面能力，不因扩展增加而隐藏。
- `extension`：默认位置，进入播放器工具面板。
- `dedicated`：拥有独立工作区，只在扩展面板保留入口。

## 验收标准

1. 搜索历史和搜索结果切换时没有横向跳动，所有边缘和文字基准线保持笔直。
2. 首页与歌词文字不会穿过搜索内容形成双层文字，搜索玻璃仍保持轻盈。
3. 播放器核心区在不同歌曲标题长度和窗口宽度下保持视觉居中。
4. 常规桌面宽度下各控制组不重叠，组内紧凑、组间有清楚留白。
5. AutoMix、听感调节和定时停播可从扩展入口正常进入，原有状态与功能不丢失。
6. 后续新增扩展项不需要修改播放器三段布局。
