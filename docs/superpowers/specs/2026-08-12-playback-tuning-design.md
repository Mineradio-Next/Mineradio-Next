# 播放速度与音调设计

## 目标

在不改变 Mineradio 主播放条结构的前提下，补齐播放器常用的倍速与独立音调能力。功能归属于“播放器工具”，不进入视觉控制台、音乐库或主传输控制区，也不引入衍生项目名称和界面。

## 入口与工具分组

播放器工具改为两个稳定分组：

- 播放：播放调节、智能衔接、定时停播。
- 声音：听感调节、播放频谱。

播放器工具最多容纳六个一级入口。达到上限后，新功能必须合并到已有入口或转移到音乐库、来源管理、视觉控制台和设置等所属区域，禁止继续堆叠成长菜单。

“播放调节”只占一个一级入口。点击后打开二级浮层，主播放条的上一首、播放/暂停、下一首以及已验收布局保持不变。

## 交互

- 倍速范围 `0.5x-2.0x`，步进 `0.05x`，常用档位为 `0.75x / 1.0x / 1.25x / 1.5x / 2.0x`。
- 音调范围 `-12` 到 `+12` 半音，步进 `1` 半音，常用档位为 `-5 / 0 / +5`。
- 倍速默认保持原音高；音调独立变化，不改变播放速度。
- 浮层顶部显示当前倍速与音调摘要，提供一键复位。
- 拖动时即时试听，松开后给出简短提示；数值使用等宽数字，避免布局跳动。
- 点击外部、按 `Esc` 或关闭播放器工具时同步收起二级浮层。
- 小窗口中二级浮层自动限制在视口内，不出现竖排文字或横向溢出。

## 音频架构

倍速直接写入每个参与播放的 `HTMLAudioElement.playbackRate`，同时开启 `preservesPitch`。当前播放器、无缝预载、Cuefield 预载、换源重建和音频图恢复创建的新元素都必须经过统一配置函数。

音调处理插入 Web Audio 主链：分析器之后、听感均衡与主增益之前。每个主播放或预载音频图拥有独立的音调节点；Cuefield 或无缝播放接管预载图时同时接管对应音调状态，避免交接瞬间音高跳变。

优先使用 `AudioWorklet` 的短延迟重叠延时处理器；不可用时使用同算法的 `ScriptProcessor` 兼容节点。两者均不可用时只把音调恢复为 `0`，倍速继续可用并在界面明确显示当前设备不支持独立音调。

## 状态与边界

- 使用独立版本化本地键保存 `{ speed, pitch }`，启动时规范化到合法范围。
- 设置对本地歌曲和所有在线来源统一生效，不写入歌曲、歌单或账号数据。
- 切歌、重新取链、播放恢复、音频元素重建后保持当前设置。
- 系统媒体会话继续报告真实 `playbackRate`。
- 音调节点初始化失败不能阻断播放；销毁音频图时必须断开节点并使迟到的异步初始化失效。
- 迷你播放器沿用当前设置，但不额外增加调音控件。

## 测试与验收

- 单元测试覆盖状态规范化、显示格式、倍速应用、音调比例和失败降级。
- 集成测试验证模块加载顺序、工具分组、二级浮层关闭行为和响应式边界。
- 音频生命周期测试验证本地/在线播放、音频重建、无缝预载和 Cuefield 预载均调用统一媒体配置。
- 完整执行 `npm test`、`npm run check`、`npm run security:audit`，随后生成 Windows 解包验收版。
