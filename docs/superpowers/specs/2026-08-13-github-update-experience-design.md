# Mineradio Next GitHub 更新体验设计

日期：2026-08-13

## 目标

Mineradio Next 在不部署自有服务器、不静默下载安装包、不引入代码签名依赖的前提下，完成 GitHub Releases 更新闭环：启动后安静检查、发现新版后在软件内说明、由用户决定是否前往官方 Release 页面下载安装。

本功能必须保持播放优先。检查失败、GitHub 不可达或响应超时均不得影响启动、播放和其他功能，也不得主动弹出错误打扰用户。

## 更新流程

1. 主界面和播放能力稳定后，后台检查 `Mineradio-Next/Mineradio-Next` 的最新公开 Release。
2. 当前版本已经是最新版本时，不显示更新入口，也不弹提示。
3. 检查失败时保持静默；用户手动检查时才在更新浮层内显示失败状态。
4. 发现更高版本后，右上角显示带红色状态点的更新入口，但不自动打开浮层。
5. 用户点击入口后查看版本号、版本摘要和最多三条重要变化。
6. 用户点击“前往 GitHub 更新”后，使用系统浏览器打开该版本的官方 GitHub Release 页面。
7. 软件不在本地下载、替换或安装文件，不自动退出播放器。

## UI 方案

采用已确认的 A 方案：居中“版本动态”浮层。

### 入口

- 继续使用桌面标题栏右侧的更新图标，不新增侧栏菜单或独立页面。
- 只有发现新版时才显示入口。
- 红色只用于状态点和轻微的激活反馈，不使用持续跳动、旋转或高亮呼吸动画。
- 入口出现使用一次 180 至 240 毫秒的淡入和轻微位移；遵循系统“减少动态效果”设置。

### 浮层

- 宽度约 440 像素，使用现有 Mineradio Next 深色玻璃材质、14 像素圆角和克制阴影。
- 背景遮罩采用中等透明度和轻模糊，确保歌词、首页文字和动态背景不会穿透干扰阅读。
- 顶部依次显示“MINERADIO NEXT · 新版本”和大号版本号。
- 正文包含一句面向用户的版本摘要，以及最多三条更新重点。
- 每条重点包含两位序号、短标题和一行说明，不展示开发提交、内部任务名或技术流水账。
- 底部主按钮为“前往 GitHub 更新”，次按钮为“稍后提醒”。
- “忽略此版本”放入右上角更多菜单，避免底部按钮拥挤。
- 底部以弱提示说明“将在系统浏览器打开官方 Release 页面”。

### 动效

- 遮罩在 160 至 200 毫秒内淡入。
- 浮层使用 220 至 280 毫秒的淡入、轻微上移和模糊消退，不使用弹簧放大。
- 版本号、摘要和更新条目依次出现，总时长不超过 420 毫秒。
- 关闭动作比打开动作略快；减少动态效果时只保留透明度变化。

## 状态设计

### 发现新版

显示完整版本动态和两个主要动作。Release 内容不足三条时按实际数量展示，不用占位文案凑数。

### 已是最新版

只在用户主动检查时显示。使用简洁确认图标、当前版本号和“知道了”，不显示更新入口。

### 网络异常

启动后的自动检查失败时完全静默。用户主动检查失败时，在同一浮层显示“暂时无法检查更新”“不会影响播放”和“重新检查”。不使用系统错误弹窗。

### 稍后提醒

关闭浮层，本次应用运行期间不再次主动提醒；下次启动若该版本仍是最新 Release，可以重新显示入口。

### 忽略此版本

将当前 Release 版本写入本地偏好。该版本不再显示入口；当 GitHub 出现更高版本时自动恢复提示。必须提供可清除该偏好的能力，避免永久失去更新提醒。

## 数据与安全边界

- 更新源固定为 `https://github.com/Mineradio-Next/Mineradio-Next` 的公开 Release。
- 只接受 HTTPS，并校验外部打开地址的主机为 `github.com` 或其受信任 Release 跳转范围。
- 版本比较使用规范化语义版本，不用字符串大小比较。
- 忽略版本和本次延后状态仅保存在本地，不上传任何用户信息。
- Release 正文按纯文本展示并进行转义，禁止把远端 HTML 注入界面。
- 自动检查设置短超时并复用现有服务端更新接口；失败不重试轰炸 GitHub。

## Release 内容约定

每个正式 Release 使用 `vX.Y.Z` 标签，并提供：

- 面向用户的一句话摘要；
- 三至五条用户可感知的新增或改进；
- 重要修复；
- 安装包名称和 SHA-256 校验文件；
- 未签名安装包的 SmartScreen 说明。

软件内只提取摘要和前三条重点，完整内容留在 GitHub Release 页面。

## 验证

- 版本低于最新 Release 时，入口出现且浮层内容正确。
- 当前版本相同或更高时，启动不显示入口。
- 自动检查断网、超时、GitHub 限流时不弹窗、不阻塞启动和播放。
- 用户主动检查失败时只在浮层内反馈，并可重新检查。
- “稍后提醒”在本次运行中不再次打扰。
- “忽略此版本”只忽略当前版本，更高版本仍可提示。
- 主按钮只打开官方 HTTPS Release 页面，不下载、不安装、不退出应用。
- 1280×720、1440×900 和高 DPI 下无溢出、遮挡或文字穿透。
- DIY 背景、歌词页、首页、桌面模式和减少动态效果下浮层均可读。
- 全量 Node 测试、CI quick check 和打包后的 Windows 冷启动回归全部通过。

## 明确不做

- 不静默下载或安装更新。
- 不接入自有更新服务器。
- 不引入强制更新。
- 不在本阶段接入差分补丁、增量包或安装器自替换。
- 不把多个镜像或网盘线路铺在浮层内。
