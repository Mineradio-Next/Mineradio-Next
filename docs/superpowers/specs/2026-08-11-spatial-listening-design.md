# 空间听感设计

## 目标

在现有“听感调节”上增加克制、真实且可维护的空间处理，让用户不离开播放器就能切换轻量环境混响、调整立体声宽度，并决定是否启用削峰保护。

本批是现有五段均衡器的第二阶段，不新增菜单，不复制 LX 的“专业声场实验室”界面，也不改变首页、播放器布局和 Cuefield 转场逻辑。

## 方案选择

评估了三种路径：

1. 直接移植 LX 的完整音效实验室。功能多，但节点、控件和状态过重，也包含容易误解的分轨与旋转环绕。
2. 只增加环境混响。风险最低，但用户缺少控制声场拥挤度的手段，功能提升有限。
3. 在现有听感图中加入环境混响、声场宽度和削峰保护。本批采用此方案，覆盖最常用的空间听感，同时沿用原版 Mineradio 的控制密度。

## 产品边界

- 环境档位：关闭、近场、小房间、音乐厅。
- 空间感控制卷积混响的干湿比例，范围 0% 至 30%。
- 声场宽度使用立体声矩阵，范围 70% 至 140%；100% 保持原始左右声道。
- 削峰保护使用 `DynamicsCompressorNode`，默认开启，但只有听感调节总开关开启时才介入。
- 不宣称“3D 耳机环绕”、HRTF 或真实空间定位。
- 不实现“仅人声”“仅伴奏”或其他假分轨。
- 不增加新的智能 DJ 转场；切歌继续由现有淡入淡出和 Cuefield AutoMix 负责。
- `captureStream` 音频回退继续直出，不为强制效果破坏音频时钟恢复。

## 交互

右侧控制台的“听感调节”区在五段均衡器后增加：

- 四段环境选择；
- 空间感滑杆；
- 声场宽度滑杆；
- 削峰保护开关。

底部播放器的听感浮层使用同一状态，增加紧凑环境分段、宽度滑杆和削峰开关。两个入口实时同步，不建立第二份设置。

选择非关闭环境、拖动空间感或宽度时自动开启听感调节。点击总开关关闭后，所有 EQ 增益平滑归零、混响回到 0%、宽度回到 100%、压缩器变为透明，但保留用户上次参数，重新开启即可恢复。

环境档位只提供合理初值，用户继续拖动空间感后仍保留当前环境名称。切换“原声”预设只还原 EQ，不清除空间参数；总开关负责整体旁路。

## 音频图

播放图扩展为：

```text
source -> analyser -> five-band EQ -> dry ------------------+
                                  -> convolver -> wet ------+-> width matrix -> limiter -> gain -> destination
```

卷积脉冲在客户端按环境参数确定性生成，不下载外部音频资源。脉冲最长控制在约 3.4 秒，避免无界内存增长。只有环境档位或空间参数改变时才重建脉冲，不在动画帧中更新。

声场宽度使用 Mid/Side 等价的四路增益矩阵：100% 时左右声道原样通过，低于 100% 时向中央收拢，高于 100% 时增强侧向差异。节点不支持时自动退回普通立体声，不影响播放。

主播放和 Cuefield 预载播放继续共用 `createListeningEffectsGraph` 与 `applyListeningEffectsToGraph`，确保无缝切歌前后参数一致。

## 状态与兼容

继续使用 `mineradio-listening-effects-v1`，新增字段：

```json
{
  "ambience": "off",
  "ambienceAmount": 0,
  "width": 1,
  "protection": true
}
```

旧状态缺少这些字段时按关闭环境、100% 宽度、开启削峰保护迁移。损坏或越界值会被归一化，不改变现有五段 EQ 数据。

## 错误与性能

- `ConvolverNode`、声道分离或合并节点不可用时，保留 EQ 和削峰保护。
- 单次脉冲生成使用有上限的采样长度；每个播放图只保存一份当前脉冲。
- 所有 AudioParam 使用短时间常数平滑，切换设置不产生明显爆音。
- 关闭听感调节不重建 `Audio` 元素或 `AudioContext`。
- 断开播放图时清理新增节点连接，避免切歌后重复路由。

## 视觉

沿用现有暗色玻璃层、细边框、分段按钮和原版滑杆。新增控制直接排列在当前听感区域内，不创建卡片嵌套，也不放大右侧控制台宽度。

底部浮层宽度保持现有 316px，新增区使用分隔线和两列紧凑控制；小窗口仍向上展开。动效只使用现有透明度、位移和状态色，遵守 reduced-motion。

## 验证

- 单元测试覆盖旧状态迁移、环境值归一化、卷积节点、宽度矩阵、削峰开关和 Cuefield 预载同步。
- 全量 `node --test` 与 `quick-check.bat fast/full` 通过。
- 隐藏 Electron QA 检查 1440x900 与 1280x720：浮层不越界、控件不重叠、状态双向同步。
- 真实播放检查切换环境、拖动宽度、关闭总开关和连续切歌时无控制台错误。
- 构建 Windows 目录包，最后只启动普通客户端供用户验收。
