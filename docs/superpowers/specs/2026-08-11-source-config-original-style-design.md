# 来源配置原版化设计

## 目标

来源配置继续提供附加来源开关、脚本文件导入、链接导入、来源切换和移除，但视觉与交互必须像 Mineradio 原有功能，不形成独立设计语言。

## 设计约束

- 沿用现有 `modal-mask`、`modal`、`modal-btn`、`fx-toggle`、`playlist-import-input` 和 GSAP 弹窗动画。
- 不使用浏览器原生复选框。开关使用原有效果设置中的整行状态块和圆点反馈。
- 弹窗内容保持单列。文件导入是一条次级命令；链接输入与提交按钮组成完整的一行，在窄屏下自然换行。
- 主标题、说明、状态、已安装列表和底部关闭操作形成清晰层级，不使用额外品牌色或 LX 名称。
- 附加来源默认关闭；视觉改动不改变现有数据、接口或播放回退顺序。

## 状态与交互

- 关闭状态使用原创中性色；开启状态使用项目香槟金强调色。
- 空列表只显示一条低对比说明，不制造空白卡片。
- 已安装来源使用紧凑列表行；当前来源显示状态标签，其余来源显示启用与移除操作。
- 导入、切换、移除期间继续在同一状态区域反馈，不增加新弹窗。

## 验证

- 检查默认关闭、点击切换、文件选择、链接导入、来源切换、移除和关闭弹窗。
- 检查 520px 以下布局无溢出。
- 运行脚本语法、经典脚本合并解析、播放回退事务和 Electron 启动检查。
