# Mineradio 听感调节设计

## 目标

在原创 Mineradio 的播放与视觉架构上增加一套可长期维护的听感调节能力。功能进入现有右侧控制台，沿用原有分组、分段按钮、滑杆、悬停和折叠动画，不引入其他项目品牌或独立风格面板。

## 本批范围

- 五段均衡器：80 Hz、250 Hz、1 kHz、4 kHz、12 kHz。
- 六个预设：原声、低频、人声、现场、夜间、自定义。
- 听感调节总开关。
- 防削波母带：启用调节时使用轻量动态压缩器，降低多频段叠加增益导致的爆音风险。
- 设置持久化，重启、普通切歌和 Cuefield 预载切歌后保持一致。
- 控制台增加“声音”页签；均衡器和原有输出设备分别作为两个折叠组。

## 不在本批范围

- 不实现标称“仅人声”或“仅伴奏”的假分轨。简单左右声道矩阵只能近似削弱居中内容，不等同于源分离。
- 不加入卷积混响、动态 HRTF 环绕或自动旋转声场。这些节点会扩大播放图和无缝切歌的风险，后续作为独立批次评估。
- 不修改平台取流、登录、歌词分析和视觉频谱算法。

## 播放图

普通播放图：

```text
MediaElementSource
  ├─> BeatAnalyser
  └─> Analyser -> EQ Input -> 5 x BiquadFilter -> Compressor -> Volume Gain -> Destination
```

关闭听感调节时不重建播放元素，只把 EQ 增益平滑回零并将压缩器设置为近似透明，避免切歌、暂停或音量淡入淡出被中断。

Cuefield 预载图通过同一个 `createListeningEffectsGraph()` 构建函数创建节点。预载音轨被接管为当前音轨时，节点引用一并接管；未接管的预载图销毁时统一断开。

极少数 `captureStream` 回退路径继续保持原始直出，只连接静音分析支路。界面会显示当前播放图是否支持听感调节，不能为了强行加效果破坏音频时钟恢复逻辑。

## 数据模型

存储键：`mineradio-listening-effects-v1`

```json
{
  "enabled": false,
  "preset": "flat",
  "gains": [0, 0, 0, 0, 0]
}
```

- 所有增益限制在 `-9 dB` 到 `+9 dB`。
- 读取损坏或旧数据时回退到关闭的原声状态。
- 手动拖动任意频段后预设切换为“自定义”。

## 界面与交互

- “声音”页签位于“常用”之后，保持控制台的横向页签结构。
- “听感调节”分组默认展开。
- 开关使用原创 `fx-toggle`；预设使用原创 `fx-seg`；频段使用原创 `fx-slider`。
- 滑杆输出实时显示带符号的 dB 值，例如 `+3 dB`、`0 dB`。
- 切换预设和开关时，音频参数以短时间常数平滑过渡，不产生硬切爆音。
- 状态行显示“等待播放”“原声直出”“已应用”或“当前音频回退为直出”。
- 控件支持键盘操作、`aria-pressed`、`role="switch"` 和清晰焦点态。

## 预设

| 预设 | 80 Hz | 250 Hz | 1 kHz | 4 kHz | 12 kHz |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原声 | 0 | 0 | 0 | 0 | 0 |
| 低频 | +5 | +3 | 0 | -1 | +1 |
| 人声 | -3 | -1 | +2 | +4 | +2 |
| 现场 | +2 | +1 | -1 | +2 | +4 |
| 夜间 | -4 | -2 | +1 | +2 | -1 |

## 验证

- 单元测试覆盖状态归一化、预设、存储、节点构建、平滑更新和销毁。
- 集成测试覆盖普通播放图与 Cuefield 预载图的连接、接管和清理。
- 全量 Node 测试与 Electron quick check 必须通过。
- 客户端验收检查声音页签、折叠组、窄屏布局、键盘焦点和切歌后状态保持。
