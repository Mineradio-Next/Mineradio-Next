# Mineradio 场景留影设计

## 目标

在 Windows 客户端中增加一个 Mineradio 原生的短片录制能力。用户可以从视觉控制台录下当前 Mineradio 窗口中的歌词、3D 视觉、背景与界面状态，形成一段可分享的 15 秒 WebM 视频。

功能统一命名为“场景留影”，界面、文件名与代码中不出现 LX 品牌。

## 范围

第一版包含：

- 录制当前 Mineradio 主窗口，保留 DOM、歌词、Canvas、WebGL 与窗口内动画。
- 录制前 3 秒倒计时，默认录制 15 秒。
- 录制中显示剩余时间，可提前完成，也可取消并丢弃本次内容。
- 完成后打开 Windows 保存对话框，输出 WebM 文件。
- 保存成功后显示文件名，并提供打开所在文件夹的入口。

第一版不包含：

- 捕获桌面、其他应用窗口、桌面歌词悬浮窗或系统通知。
- 摄像头、麦克风、系统声音或歌曲音频录制。
- MP4、GIF、H.264 转码、片段剪辑或录制历史库。
- 自定义分辨率、帧率、码率或时长。

首版保持静音是明确的产品边界：窗口视频捕获在 Windows/Electron 中稳定，应用音频与系统音频捕获受驱动、输出设备和 Chromium 路由影响。后续音视频合成应作为独立批次实现和验收。

## 入口与视觉

入口位于视觉控制台“常用”页，新增独立的“场景留影”分组，放在“用户存档”之后。“用户存档”保存参数，“场景留影”保存当下画面，两者语义相邻但不混在同一工具栏。

静止状态只显示一个紧凑横向工具：左侧是圆形取景标记，中间是标题与“15 秒 · 当前窗口 · WebM”，右侧是“开始”按钮。录制时工具切换为红色状态点、剩余秒数、进度轨、“完成”和“取消”，不弹出遮挡画面的模态框。

倒计时以窗口中央的轻量数字叠层显示，背景透明且不冻结播放器。数字淡入、缩放后退场；录制开始时叠层完全移除，因此不会进入最终视频。录制中的状态条属于视觉控制台界面的一部分：控制台若保持打开会被录入，用户也可以在倒计时后收起控制台。

动画遵循现有缓动和 `prefers-reduced-motion`。减少动态时只改变透明度，不执行缩放。

## 架构

### 窗口源授权

渲染进程通过预加载层请求主窗口的媒体源。主进程只在可信 Mineradio 主文档发起 IPC 时返回 `mainWindow.getMediaSourceId()`，不枚举或暴露桌面上的其他窗口。

渲染进程使用带 `chromeMediaSource: desktop` 与指定 source ID 的 `getUserMedia` 创建只含视频轨的 `MediaStream`。分辨率跟随当前窗口，最高 1920×1080，帧率上限 30 FPS。

### 录制与状态机

独立模块维护 `idle → countdown → recording → saving → idle` 状态，并允许：

- `countdown → idle`：取消倒计时。
- `recording → saving`：提前完成，保存已有内容。
- `recording → idle`：取消并丢弃。
- 任意活动状态在窗口卸载或轨道结束时释放资源并回到空闲。

`MediaRecorder` 按 VP8、普通 WebM、VP9 的顺序选择当前 Chromium 支持的格式，30 FPS 码率为 5 Mbps，每 500 毫秒产生一个片段。录制片段只在当前会话内存中存在，不写入应用数据目录。

### 保存通道

录制完成后将 Blob 转为 `ArrayBuffer`，通过一个专用 IPC 发送二进制数据。主进程执行以下校验：

- IPC 必须来自可信 Mineradio 主窗口。
- MIME 必须是允许的 WebM 类型。
- 文件大小必须大于 1 KB 且不超过 32 MB。
- 文件名经过 Windows 非法字符清洗并强制使用 `.webm`。

主进程随后显示保存对话框并一次性写入目标文件。取消保存只丢弃内存数据，不创建临时文件。渲染进程不会获得任意路径写入能力。

## 错误处理

- 非 Electron 环境或缺少 `MediaRecorder` 时禁用开始按钮，并显示“当前环境不支持窗口留影”。
- 无法取得主窗口源时恢复空闲状态并提示，不影响播放与视觉渲染。
- 视频轨意外结束时停止录制；已有有效数据则进入保存，没有数据则提示失败。
- 空文件、超出大小限制、保存失败或用户取消保存都释放 Blob、录制器和全部媒体轨。
- 同一时间只允许一个录制会话；重复点击不会创建第二个 `MediaRecorder`。

## 验收

- 视觉控制台常用页能找到“场景留影”，首页与其他页面布局不变化。
- 开始后显示 3、2、1 倒计时，倒计时不进入成片。
- 录制时剩余时间与进度更新，提前完成能保存短于 15 秒的有效文件。
- 取消不会弹保存对话框，也不会残留媒体轨或临时文件。
- 保存的 WebM 能在 Windows 支持的播放器或 Chromium 中打开，画面包含当前 Mineradio 窗口而不包含其他窗口。
- 无法从预加载桥获取其他桌面源；未信任 IPC、非法 MIME、空文件和超大文件被拒绝。
- 录制失败、取消保存和轨道中断不影响歌曲播放。
- 1440×900 与 1280×720 下控制台无重叠、溢出或按钮跳位；减少动态设置生效。

## 测试

- 单元测试覆盖 MIME 选择、文件名、状态互斥、提前完成、取消与资源释放。
- 集成测试覆盖入口、模块加载、可信窗口 source ID IPC、32 MB 限制和 WebM 保存过滤器。
- Electron smoke test 验证主窗口 source ID 可取得、MediaRecorder 可创建、录制产生非空 WebM、保存取消路径不会报错。
- 浏览器视觉测试覆盖空闲、倒计时、录制和保存状态，以及 1440×900、1280×720 和减少动态模式。

## 后续边界

音频合成、MP4/H.264、GIF、片段历史与 Wallpaper Engine 资源转换不塞进本批。它们只有在当前 WebM 录制链稳定后才进入独立设计，避免把录制、转码与资源管理绑成一个难维护模块。
