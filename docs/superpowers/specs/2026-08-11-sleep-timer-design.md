# Mineradio 定时停播设计

## 目标

在现有底部播放器中补齐定时停播能力。它属于播放控制，不新增页面、不进入视觉控制台，也不改变原版播放器的视觉层级。

## 交互

- 在底部播放器右侧控制组增加时钟图标。
- 点击图标打开轻量浮层；再次点击、点击外部或按 `Escape` 关闭。
- 提供 `15`、`30`、`60`、`90` 分钟和“本曲播完”五个选项。
- 激活后，图标显示稳定的小型状态标记；浮层显示剩余时间或“本曲播完后停止”。
- 浮层提供单独的取消操作。关闭浮层不会取消计时。
- 到时只停止播放，不退出应用，避免桌面模式、未保存状态和后台任务被意外中断。

## 状态

状态只有三种：

- `off`：未启用。
- `deadline`：保存绝对截止时间，应用重启后仍可恢复剩余时间。
- `track-end`：拦截下一次自然换曲，当前播放结束后停止。

过期的截止时间在启动时直接清理，不会在应用刚启动且尚未恢复播放时误触发。

## 播放边界

- 固定分钟计时到期时，先清理自动过渡和无缝衔接，再使用播放器现有淡出逻辑暂停。
- “本曲播完”启用后，Cuefield AutoMix 不再为当前曲触发切歌，专辑无缝衔接也不再提前交叉淡化。
- 当前曲自然结束时，正常结算聆听记录，但不执行单曲循环、队列下一首或自动混音恢复。
- 手动暂停不取消计时；用户可继续播放，原截止时间保持不变。
- 手动切歌后，“本曲播完”跟随当前正在播放的歌曲，在下一次自然结束时停止。

## 兼容与可访问性

- 浮层沿用底部控制条现有玻璃质感、字号、边框和动效时长。
- 控件尺寸固定，不因剩余时间变化挤压播放器布局。
- 支持键盘焦点、`aria-expanded`、`aria-pressed` 和状态播报。
- 减少动态模式下移除浮层位移动画。
- 窄窗口保留时钟按钮，浮层宽度受视口限制。

## 测试

- 单元测试覆盖状态归一化、截止时间恢复、倒计时格式、本曲结束消费和到时淡出暂停。
- 集成守卫覆盖 HTML、CSS、模块加载顺序以及普通播放、无缝衔接、AutoMix 三条闸门。
- 运行全部 Node 测试、项目快速检查、Electron 烟测和安装包构建。

## 不在本批范围

- 到时退出应用或关闭 Windows。
- 自定义分钟输入、按时钟时间预约、每日重复计划。
- 手机遥控端设置定时器。
- 新菜单、新页面或视觉控制台分组。
