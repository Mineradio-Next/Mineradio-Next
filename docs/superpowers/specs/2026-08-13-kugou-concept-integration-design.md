# 酷狗概念版接入设计

## 目标

在现有 Mineradio-Next 中增加“酷狗概念版”作为正式内置音源。界面上与“酷狗音乐”并列显示，但账号、接口、权限、缓存和用户内容完全隔离。普通酷狗现有行为保持兼容。

## 用户体验

来源管理中显示两行独立来源：

- 酷狗音乐
- 酷狗概念版

每行都有独立的显示开关和连接状态。显示开关只控制是否参与搜索、推荐和来源状态，不会退出账号。未登录也可以显示并搜索公开结果；需要账号、会员或购买权限的操作由对应平台状态决定。

账号中心提供两个并列登录入口。登录、刷新、退出只作用于当前入口，两个账号可以同时登录。界面不使用上游项目名称或 LX 命名。

## 内部模型

歌曲继续使用 `provider: 'kugou'`，增加版本字段：

```js
{
  provider: 'kugou',
  kugouVariant: 'standard' | 'concept'
}
```

概念版适配器放在现有酷狗模块内部，普通酷狗适配器作为兼容基线。这样播放器、收藏、来源回退和上游同步不需要复制一套平台系统。

账号和缓存按版本分区：

```text
普通酷狗：.kugou-cookie
概念版：.kugou-concept-cookie
```

两边分别保存 Cookie/Token、用户 ID、设备信息、会员状态、歌单、收藏和播放缓存。概念版的 AppID、ClientVer、签名盐、登录续期和风控参数只由 concept adapter 使用。

## 数据流

默认搜索同时请求已显示的普通酷狗和概念版，结果合并去重并保留 `kugouVariant`。搜索结果显示来源标签，不增加顶部搜索按钮；现有搜索筛选提供普通酷狗/概念版的来源筛选。

播放、歌词和音质请求根据歌曲的 `kugouVariant` 进入对应适配器。请求失败按歌曲来源优先尝试另一酷狗版本，再进入其他已启用平台的现有回退链。

错误分类保持用户可理解：版权或歌曲不存在时自动换源；登录缺失提示登录对应平台；会员限制提示权限原因并继续尝试其他来源。内部错误码不直接展示。

## 分阶段范围

### 第一阶段：核心闭环

- 来源列表和显示开关
- 独立登录、状态刷新和退出
- 普通酷狗/概念版搜索
- 概念版播放地址、歌词和音质降级
- 按版本隔离缓存
- 酷狗双版本与其他平台的自动回退
- 普通酷狗回归测试

### 第二阶段：账号内容

- 概念版推荐
- 概念版歌单与歌曲加载
- 概念版收藏、取消收藏和添加到歌单
- 概念版会员状态细化

每日 VIP 领取等非核心接口不进入播放主链，待第二阶段稳定后单独评估。

## 错误处理与回滚

概念版接口失败时保留原普通酷狗路径和原 Cookie 文件，不迁移、不覆盖。概念版功能可以由来源开关整体关闭；关闭后普通酷狗行为与接入前一致。所有新增状态字段都使用默认值兼容旧用户数据。

## 验收标准

1. 只开启普通酷狗时，搜索、播放、歌词、登录、收藏和歌单与接入前一致。
2. 只开启概念版时，能独立登录、搜索、播放和加载歌词。
3. 两个账号同时登录时，昵称、会员状态、退出操作和缓存互不覆盖。
4. 关闭概念版后，搜索和推荐不再返回概念版结果，普通酷狗仍可用。
5. 概念版歌曲播放失败时，能按规则自动换源并给出清晰提示。
6. 概念版接口不可用时，应用仍能启动，普通酷狗和其他平台不受影响。

## 来源与许可证

概念版协议实现参考 `MakcRe/KuGouMusicApi` 的 MIT 代码，移植时保留版权和许可证说明，并在 `NOTICE.md` 记录来源。只参考 API 适配逻辑，不复制上游客户端 UI、品牌资源或项目名称。
