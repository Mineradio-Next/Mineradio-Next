# 播放器频谱与前级增益设计

## 目标

在不改变 Mineradio 原有播放器骨架的前提下，补齐两个高价值能力：底栏实时频谱和听感链前级增益。两者沿用现有玻璃层、封面取色、播放器工具分组和 Web Audio 图，不复制 LX 的内联界面或命名。

## 信息架构

- 底栏频谱是播放器的轻量播放反馈，画布固定在进度条后方，不参与排版、不遮挡文字和按钮。
- 频谱开关放在“播放器工具”扩展区，与智能衔接、听感调节和定时停播同级。
- 前级增益放在听感调节面板的 EQ 之前；播放器弹层提供紧凑常用控制，视觉控制台保留完整控制。
- 原有“音域频谱”继续作为视觉效果的高级诊断工具，两者职责分离。

## 音频链

音频处理顺序为：输入 -> 前级增益 -> 五段 EQ -> 空间混合 -> 声场宽度 -> 峰值保护 -> 输出。前级范围为 -12 dB 到 +6 dB，默认 0 dB，线性增益按 `10^(dB/20)` 计算。主开关关闭时前级回到 0 dB，Cuefield 预备音轨和当前音轨同步更新。

旧版状态缺少 `preampDb` 时迁移为 0 dB，不改变已有用户听感。只启用削峰保护、不包含任何实际处理时，仍视为旁路状态。

## 频谱表现

- 复用主分析器的 `frequencyData`，不新建 AnalyserNode。
- 采用 28 根圆角短柱和一条低亮度基线，低频在左、高频在右。
- 颜色优先读取封面的区域主色、强调色和亮色，降低饱和度与不透明度后绘制；无封面色时回退到现有青绿色强调色。
- 正常播放最高 30 FPS；暂停后平滑衰减并在静止后降低刷新；后台、隐藏或减少动态效果时降到低频刷新或静止。
- Canvas 使用设备像素比适配但限制像素预算，尺寸变化不引发布局位移。

## 状态与备份

频谱开关使用 `mineradio-player-spectrum-v1` 持久化，默认开启。该偏好加入完整备份的“偏好设置”类别。听感状态继续使用 `mineradio-listening-effects-v1`，通过字段兼容完成无感迁移。

## 测试与验收

- 验证前级默认值、范围、dB 转线性增益和音频节点顺序。
- 验证当前播放图与 Cuefield 预备图同步更新。
- 验证频谱复用 `frequencyData`、具有暂停衰减、后台节流和减少动态效果分支。
- 验证画布、开关、加载顺序和备份键均已接入，且没有 LX 可见命名。
- 运行全量 Node 测试、完整 quick-check、diff 检查，并同步到 Windows 解包客户端后核对 SHA-256。
