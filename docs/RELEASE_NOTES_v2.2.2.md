# Mineradio Next v2.2.2

<!-- mineradio-update-summary:start -->
新增酷狗概念版账号、歌单与播放支持
<!-- mineradio-update-summary:end -->

## 主要变化

<!-- mineradio-update-highlights:start -->
- 酷狗概念版：支持独立扫码或 Cookie 登录、每日推荐、搜索、播放与歌词
- 账号同步：支持读取云歌单和红心状态，并可收藏、取消收藏或写入指定歌单
- 稳定性：隔离普通酷狗与概念版会话，修复封面串台、榜单缺图和播放错误提示
<!-- mineradio-update-highlights:end -->

## 其他改进

- 概念版播放链接失效时会重新取链，并在可行时逐级降低音质
- 登录失效、会员限制、版权不可用和临时网络异常使用不同提示
- 只读会话不会显示虚假的收藏成功，恢复权限后可继续同步
- 酷狗榜单缺少封面时按歌曲信息补全，单首失败不会阻塞整个榜单

## 安装

下载 `Mineradio-Next-2.2.2-Setup.exe`，并使用同一 Release 中的 `SHA256SUMS.txt` 校验文件完整性。

当前安装包未进行商业代码签名，Windows 可能显示未知发布者提示。

## 已知边界

- 音乐平台能力受接口变化、账号地区、版权和会员权益影响
- 软件内更新入口会打开 GitHub Release 页面，不会静默下载或执行安装包
- 酷狗概念版与普通酷狗需要分别登录，二者的账号数据不会自动合并
